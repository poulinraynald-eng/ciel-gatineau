# ciel-gatineau

Compagnon de télescope : une page web pour un vieil iPad Air (iOS 12), conçue pour un Celestron NexStar 8SE avec StarSense AutoAlign, sous le ciel de Gatineau.

- `index.html` : l'application complète, en un seul fichier (ciel du soir, carte, guide de première sortie, aide-mémoire, carnet).
- `sw.js` : garde une copie de la page pour l'utiliser sans Wi-Fi.

Positions calculées avec [Astronomy Engine](https://github.com/cosinekitty/astronomy) (licence MIT). Étoiles, constellations et objets Messier tirés de [d3-celestial](https://github.com/ofrohn/d3-celestial) (licence BSD).
