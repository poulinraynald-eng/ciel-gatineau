Installer (une étape à la fois)

1. Ouvre cette page dans Safari (iPad) ou dans ton navigateur (PC).
2. Touche « Copier » sous l'option choisie.
3. iPad : Réglages → Apps → Mail → Signature → efface l'ancienne → colle.
   Outlook (nouveau ou web) : Paramètres → Comptes → Signatures → colle.
4. Envoie-toi un courriel test pour vérifier.
